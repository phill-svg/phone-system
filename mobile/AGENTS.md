# Expo HAS CHANGED

This app is pinned to **Expo SDK 54** on purpose: the public Apple App Store Expo Go
only supports SDK 54 (SDK 55+ Expo Go is stuck in Apple review), and the user tests on a
real iPhone via Expo Go without a paid Apple Developer account. Do NOT upgrade the SDK
without a plan for how the user will run it. Read the exact versioned docs at
https://docs.expo.dev/versions/v54.0.0/ before writing any code.
